Traffmonetizer Installer

Script universal para instalar o Traffmonetizer em qualquer servidor

AWS Oracle Cloud Google Cloud Azure Vultr Hetzner DigitalOcean

Instalação Rápida

Copie e cole os comandos abaixo no seu servidor:

curl -O https://raw.githubusercontent.com/gpartnerllc-png/TRAFF/main/install-traffmonetizer.sh
chmod +x install-traffmonetizer.sh
TOKEN=seu_token_aqui QUANTIDADE=1 bash install-traffmonetizer.sh

Substitua seu_token_aqui pelo seu token real do Traffmonetizer.

Exemplos de Uso

1 container:

TOKEN=seu_token bash install-traffmonetizer.sh

3 containers:

TOKEN=seu_token QUANTIDADE=3 DEVICE_NAME=Oracle bash install-traffmonetizer.sh

12 containers (exemplo):

TOKEN=seu_token QUANTIDADE=12 DEVICE_NAME=AWS PREFIXO=traff bash install-traffmonetizer.sh

Recursos

Detecção Automática x86_64 / ARM64 / ARM32
Múltiplos Containers Rode quantos quiser
Todas as Clouds AWS, GCP, Azure, Oracle...
Reinício Automático --restart always

Comandos Úteis

# Ver containers rodando
docker ps

# Ver logs
docker logs traff-1

# Reiniciar um container
docker restart traff-1

# Parar todos
docker stop $(docker ps -q --filter name=traff)

# Remover todos
docker rm -f $(docker ps -aq --filter name=traff)
